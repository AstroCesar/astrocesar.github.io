Science

Astronomy · Large Surveys

Experiencia procesando millones de objetos en surveys internacionales como APOGEE, Gaia y Rubin. Pipelines de reducción, análisis estadístico y visualización de datos complejos a gran escala.

Proyectos
✦ CAPOS — Bulge Cluster APOgee Survey
Large-scale spectroscopic survey of 18 Galactic bulge globular clusters using APOGEE-2S. Co-founding member. 9+ papers, 303 confirmed members.
⌘ Data Science Scripts
Herramientas de Python para análisis espectroscópico y procesamiento de surveys astronómicos. Equivalent Width, membership classification y más.
Pipelines espectroscópicos
Reducción y análisis automatizado de datos de VLT/FLAMES y Magellan/MIKE. Integración con MOOG y BACCHUS para abundancias químicas estelares.
Determinación de membresía estelar
Clasificación de miembros de cúmulos con datos de Gaia y surveys ground-based. Combinación de cinemática y química para selección robusta.
Repositorio de herramientas · en desarrollo
Scripts públicos para la comunidad: reducción de datos espectroscópicos, visualización y análisis estadístico.
